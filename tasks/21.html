Creating HOF (higher order function) and composition

  • Task 1

    • Given

      Write a higher-order function compose that will take an arbitrary number of functions as arguments and create a composition from them. Write a curry function (modifyArray) that will first take a function (modifyCondition) as an argument, and then take an array of strings (data) as an argument, the curry function should return the modified array according to the condition (modifyCondition) that came at the beginning of the curry function. Write compositions allToLower and capitalizeAllFirst using your own compose and modifyArray that will take an array of strings and return the result of the task

    • Task

      const testArray = ["CusTom", "Web", "aNd", "MoBile", "PlaTfoRms"];

      1. allToLower - takes testArray -> converts strings so that all characters are converted to lowercase 'Result: custom - web - and - mobile - platforms length: 39'

      2. capitalizeAllFirst - takes testArray -> converts strings so that only the first character is in uppercase, the rest in lowercase, combines them into one string with the symbol'-' -> outputs 'Result: Custom-Web-And-Mobile-Platforms length: 31'

    • Examples

      • capitalizeAllFirst(arr) - 'Result: Custom-Web-And-Mobile-Platforms length: 31'
      • allToLower(arr) - 'Result: custom - web - and - mobile - platforms length: 39'
