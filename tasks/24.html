      • Given

        Function for generating ID

        function generateId() {
        return "_" + Math.random().toString(36).substr(2, 9);
        }

      • Task

        1) Create a TodoItem class with fields (properties): id (generated in the constructor using a function), name, checked (default false). For the checked field, write a getter and setter (add validation: the field can only accept the boolean value true or false)

        2) Create a TodoList class with fields: id (generated in the constructor using a function), name, items (default empty array). Add the following methods:
        - addItem - a method that adds elements to the array (you need to validate the TodoItem type)
        - removeItemById - a method that removes an element from the array by id
        - getItemById - a method that returns the TodoItem element from the array by id

        3) Create an instance of the TodoList class;

        4) Create 4 instances of the TodoItem class, add them to the TodoList and output an instance of the TodoList class to the console.

        5) Change the checked value of one TodoItem instance and output the TodoList to the console (this field in the items array should be updated)

        6) Remove 2 TodoItem instances from the TodoList and output the TodoList to the console (only 2 TodoItem instances should remain in the items array)
