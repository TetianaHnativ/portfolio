        • Task 4

          • Task

            Write a fetchSWAPI function that will accept the final resource, make a request to SWAPI and return a response as an object. The fetchSWAPI function will take 2 parameters:
            - resource - a string - the final resource (for example, 'planets/') or the full url to SWAPI (for example, https://swapi.py4e.com/api/planets/1/ ), in the function to check and build the final url
            - throwError - a boolean value - whether to throw an error in case of an unsuccessful reverse. The default is false.

            The fetchSWAPI function should check whether the request was successful. In case of an error, it should be processed - the resource and error should be displayed in the console. Also, if throwError is true, then throw the error further. The function should return a parsed response object from the API. The function contains the root url to the SWAPI, adds the final resource and makes the request.

            After implementing the function, you need to test it by calling it several times with the parameters as indicated below and display the result of the requests - testFetchSWAPI.

          • Examples

            • person - {name: "Luke Skywalker", height: "172", ...}
            • film - {title: "A New Hope", episode_id: 4, ...}
            • films/1001/ fetchSWAPI error Error: Failed with status code: 404
            • film1001Id undefined
            • films/1101/ fetchSWAPI error Error: Failed with status code: 404
              testFetchSWAPI error Error: Failed with status code: 404

          • Result
